# Облако ДурКер на Google Apps Script

Бесплатный «сервер» игры: Google Таблица хранит игроков, партии, турниры, а скрипт отвечает игре и Telegram-боту.

**Что делает:**
- считает очки сам — накрутить с телефона нельзя;
- засчитывает онлайн-матч, только когда итог прислали оба игрока;
- ведёт сезон по месяцам и выбирает чемпиона месяца;
- проводит турниры на 4 и 8 игроков;
- через бота @durocker_bot отвечает на /top, /daily, /tournament, /subscribe и каждый вечер в 21:00 по Москве пишет итоги дня в подписанные чаты.

## Деплой (один раз, ~5 минут)

1. Открыть [sheets.new](https://sheets.new) — создастся пустая таблица. Назвать её «ДурКер — база».
2. В таблице: **Расширения → Apps Script**.
3. Слева **Code.gs**: стереть всё и вставить содержимое `apps-script/Code.gs`.
4. **Настройки проекта** (шестерёнка слева):
   - включить «Показывать файл манифеста appsscript.json», открыть его в редакторе и вставить `apps-script/appsscript.json`;
   - ниже, **Свойства скрипта → Добавить свойство**: имя `TG_TOKEN`, значение — токен бота из @BotFather (`/mybots → @durocker_bot → API Token`). Токен вставляешь только сюда, больше никуда.
5. Сверху выбрать функцию `setup` → **Выполнить**. Google попросит доступ к таблице и внешним запросам — разрешить: «Дополнительно → Перейти к проекту (небезопасно)», проект твой. Появятся листы Players, Games, Daily, Matches, Tournaments и остальные.
6. **Развернуть → Новое развёртывание**:
   - тип — **Веб-приложение**;
   - «Запуск от имени» — **меня**;
   - «Кто имеет доступ» — **Все**;
   - **Развернуть** и скопировать адрес вида `https://script.google.com/macros/s/…/exec`.
7. Выбрать функцию `setWebhook` → **Выполнить**. Бот начнёт отвечать на команды.
8. Выбрать `installTriggers` → **Выполнить**. Итоги дня будут уходить в 21:00 по Москве.
9. В игре: в `js/cloud.js` вписать адрес в `const CLOUD_URL = '…/exec';`, закоммитить и запушить. Проверить можно и без коммита: открыть сайт с `?cloud=<адрес>`.

**После правок Code.gs:** Развернуть → Управление развёртываниями → карандаш → «Новая версия». Адрес не меняется, `setWebhook` повторять не нужно.

## Проверка

- `<адрес>?a=ping` в браузере — `{"ok":true,…}`.
- `<адрес>?a=board` — таблица лидеров в JSON.
- Боту в личку `/start` — ответ с кнопкой «Играть».
- В группе: добавить бота, `/subscribe`, `/tournament 4`.

## Как устроено

| Запрос | Что делает |
|---|---|
| `register` | выдаёт игроку секрет; в таблице хранится только его SHA-256 |
| `report` | итог партии. Очки считает сервер: Студент 1, Валера 2, Шулер 4, босс 5, финальный Шулер 8, дейли 3, неделя 5, онлайн 5. Не чаще раза в 20 с, за ботов не больше 60 очков в сутки, дейли — раз на день, неделя — раз в день |
| `report` (онлайн) | хозяин и гость присылают итог с одним номером матча. Сошлось (у одного победа, у другого поражение) — засчитано, нет — матч «спорный» |
| `board`, `top` | таблица лидеров, дейли, сезон и чемпион прошлого месяца. Кэш 60 с |
| `t_create`, `t_join`, `t_state`, `t_report` | турнир на выбывание. Итог матча подтверждают оба; если не сошлось — матч переигрывают. Победитель получает титул «Чемпион турнира» |

## Ограничения Google

- Ответ 1–3 с, после простоя первый запрос до 5–8 с. Игра не ждёт: очки отправляются в фоне.
- Одновременно до 30 выполнений. Запись идёт под блокировкой, так что десятков игроков хватает с запасом.
- Бесплатные квоты в сутки: ~20 000 запросов к внешним адресам (сообщения боту), 90 минут работы триггеров. Для дворовой игры это очень много.
- Telegram иногда присылает одно сообщение повторно: Apps Script отвечает переадресацией. Повторы отсекаются по номеру обновления.
- Если облако не отвечает, игра минуту не обращается к нему и показывает таблицу по-старому, через MQTT.
