# Дурокер

Дурак на 52 карты, где отбиваются покерными комбинациями. Подача — как в Balatro и за столом блэкджека: раздача из колоды, веер карт, всплывающие названия комбинаций, тряска стола на сильных ходах.

Работает в браузере на телефоне и компьютере. Можно играть с ботом или онлайн с другом по коду стола.

## Правила

- Колода 52 карты, на руке 8, козырь лежит под колодой.
- Атакуешь одиночкой, парой, сетом, двумя парами, каре или пятикарточной комбинацией (стрит, флеш, фулл-хаус, стрит-флеш).
- Кроют тем же числом карт и комбинацией старше. Одиночку бьют как в обычном дураке: старшей той же масти или козырем.
- Внутри одного типа комбинации сначала решает число козырей, потом старшинство карт.
- Отбился — атакующий может подкинуть комбинацию с номиналом, который уже лежит на столе. Не можешь — «Беру», и атакующий подкидывает вдогонку.
- За ход в атаке не больше карт, чем было у защитника, и не больше 8.
- Первым ходит тот, у кого младший козырь. Колода кончилась — кто первым скинул все карты, тот не дурак.

Старшинство: одиночка → пара → сет → две пары → каре → стрит → флеш → фулл-хаус → стрит-флеш. Сравниваются только комбинации с одинаковым числом карт.

## Онлайн

Онлайн идёт напрямую между браузерами через WebRTC ([PeerJS](https://peerjs.com/)). Свой сервер не нужен: PeerJS только помогает браузерам найти друг друга.

1. Нажми «Онлайн» → «Создать стол». Появится код из 4 символов.
2. Друг открывает этот же сайт, жмёт «Онлайн» и вводит код.
3. Партию ведёт хозяин стола. Гость получает только свою руку и число карт соперника, чужие карты к нему не уходят.

## Запуск

Сборка не нужна, это статический сайт.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

Settings → Pages → Source: «Deploy from a branch» → ветка `main`, папка `/ (root)`. Через минуту сайт будет на `https://<логин>.github.io/<репозиторий>/`. Эту ссылку и кидаешь другу.

## Устройство

| Файл | Что внутри |
|---|---|
| `index.html` | разметка стола, лобби и правил |
| `css/style.css` | стиль, вёрстка для телефона и для ПК (от 900 px) |
| `js/rules.js` | колода, оценка комбинаций, кто кого бьёт, проверка хода |
| `js/engine.js` | ход партии: атака, защита, подкидывание, «беру», «бито», добор, конец игры |
| `js/bot.js` | бот «Дядя Валера» |
| `js/net.js` | онлайн-стол на PeerJS |
| `js/ui.js` | отрисовка, анимации, лобби, клавиатура |

На ПК работает клавиатура: `Enter` — главная кнопка, `Esc` — снять выбор, `B` — «Беру» / «Бито» / «Хватит».
