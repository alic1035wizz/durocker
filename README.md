# Дурокер

Дурак на 52 карты, где отбиваются покерными комбинациями. Подача — как в Balatro и за столом блэкджека: раздача из колоды, веер карт, всплывающие названия комбинаций, тряска стола на сильных ходах.

Работает в браузере на телефоне и компьютере. Можно играть с ботом или онлайн с другом по коду стола.

## Правила

- Колода 52 карты + 2 джокера, на руке 8, козырь лежит под колодой.
- Атакуешь одиночкой, парой, тройкой, двумя парами, каре или пятью картами.
- Кроют **тем же числом карт** и комбинацией старше. Одиночку бьют как в обычном дураке: старшей той же масти или козырем.
- Внутри одного типа сначала решает число козырей, потом старшинство карт, потом меньше джокеров.
- Отбился — атакующий может подкинуть комбинацию с номиналом со стола. Не можешь — «Беру», атакующий подкидывает вдогонку.
- **Перевод** (включается при выборе соперника или создании стола): пока на атаку никто не ответил, можно перевести её комбинацией того же типа и старшинства.
- За ход в атаке не больше карт, чем у защитника, и не больше 8.
- Первым ходит тот, у кого младший козырь. Колода кончилась — кто первым скинул все карты, тот не дурак.

| Карт | Старшинство |
|---|---|
| 1 | старшая той же масти или козырь |
| 2 | пара |
| 3 | мини-флеш → мини-стрит → сет → мини-стрит-флеш |
| 4 | две пары → каре |
| 5 | стрит → флеш → фулл-хаус → стрит-флеш |

**Джокер** становится той картой, которая делает комбинацию сильнее. Одиночный джокер — старший козырь, его бьёт только козырной туз.

**Серия до 21:** проигравший партию получает столько штрафных очков, сколько карт у него осталось. Кто набрал 21, проиграл серию.

**Соперники:** Студент (легко), Дядя Валера (средне), Шулер (помнит забранные тобой карты, а в конце колоды знает твою руку целиком).

При защите игра пишет, чем можно покрыть атаку, подсвечивает подходящие карты и по кнопке «Подсказка» выбирает самый дешёвый ответ.

## Онлайн

Онлайн идёт напрямую между браузерами через WebRTC ([PeerJS](https://peerjs.com/)). Свой сервер не нужен: PeerJS только помогает браузерам найти друг друга.

1. Нажми «Онлайн» → «Создать стол». Появится код из 4 символов.
2. Друг открывает этот же сайт, жмёт «Онлайн» и вводит код.
3. Партию ведёт хозяин стола. Гость получает только свою руку и число карт соперника, чужие карты к нему не уходят.
4. На ход 30 секунд. Время вышло — игра сама говорит «Беру», «Бито» или «Хватит», а в атаке ходит младшей картой.

## Запуск

Сборка не нужна, это статический сайт.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

Settings → Pages → Source: «Deploy from a branch» → ветка `main`, папка `/ (root)`. Через минуту сайт будет на `https://<логин>.github.io/<репозиторий>/`. Эту ссылку и кидаешь другу.

## Устройство

| Файл | Что внутри |
|---|---|
| `index.html` | разметка стола, лобби и правил |
| `css/style.css` | стиль, вёрстка для телефона и для ПК (от 900 px) |
| `js/rules.js` | колода, джокеры, оценка комбинаций, кто кого бьёт, перевод, подсказки |
| `js/engine.js` | ход партии, серия до 21, таймер онлайн |
| `js/bot.js` | три соперника |
| `js/net.js` | онлайн-стол: что видит гость, как ходы доходят до хозяина |
| `js/transport-peer.js` | канал связи для сайта (PeerJS) |
| `js/transport-room.js` | канал связи для страницы внутри Claude |
| `js/ui.js` | отрисовка, анимации, подсказки, лобби, клавиатура |
| `tools/build-artifact.py` | собирает всё в одну страницу для Claude |

На ПК работает клавиатура: `Enter` — главная кнопка, `H` — подсказка, `B` — «Беру» / «Бито» / «Хватит», `Esc` — снять выбор.
