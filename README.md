# Дурокер

Дурак на 52 карты, где отбиваются покерными комбинациями. Подача — как в Balatro и за столом блэкджека: раздача из колоды, веер карт, всплывающие названия комбинаций, тряска стола на сильных ходах.

Работает в браузере на телефоне и компьютере, ставится на экран «Домой» как приложение и открывается в Telegram: **[@durocker_bot](https://t.me/durocker_bot)** → «🃏 Играть». Можно играть с ботом или онлайн с другом — по ссылке-приглашению или коду стола.

## Правила

- Колода 52 карты + 2 джокера, на руке 8, козырь лежит под колодой.
- Атакуешь одиночкой, парой, тройкой, двумя парами, каре или пятью картами.
- Кроют **тем же числом карт** и комбинацией старше. Одиночку бьют как в обычном дураке: старшей той же масти или козырем.
- **Перекрытие:** на атаку из 2+ карт можно лечь комбинацией старшего типа ровно на одну карту больше (на две пары — стритом, на пару — сетом); атакующему +1 заряда. Вахтёр запрещает.
- **Подкидывание по типу:** если карты стола сложились в комбинацию (две десятки — пара), такую же можно подкинуть любым номиналом.
- **Апгрейд:** пока защитник думает, атакующий раз за ход докладывает карты к непокрытой атаке, делая её старше.
- **⟳ Подбор** — одна кнопка листает все допустимые ходы.
- Внутри одного типа сначала решает число козырей, потом старшинство карт, потом меньше джокеров.
- Подкидывают только **комбинацией** с номиналом со стола. Не можешь крыть — «Беру», атакующий подкидывает вдогонку.
- Перевод: пока на атаку никто не ответил, её можно перевести комбинацией того же типа и старшинства.
- Колода кончилась — кто первым скинул все карты, тот не дурак.

| Карт | Старшинство |
|---|---|
| 1 | старшая той же масти или козырь |
| 2 | пара |
| 3 | мини-флеш → мини-стрит → сет → мини-стрит-флеш |
| 4 | две пары → каре |
| 5 | стрит → флеш → фулл-хаус → стрит-флеш |

**«Могнул».** Покрыл комбинацией старшего типа — сопернику сразу +1 штраф, на экране хайп-фраза.

**Заряд.** Копится за «могнул», перевод, одиночку, покрытую той же мастью без козыря, и три отбитые атаки за ход. Три деления — выбираешь одну из двух карт-действий: Щит, Разворот, +2, Смена козыря.

**Матч.** До нужного числа побед в партиях: одна партия, до 2 или до 3 побед. Карьера: соседи — до 2, боссы — до 3; дейли и босс недели — одна партия; своя игра и онлайн — на выбор (по умолчанию до 2). Штрафные очки (карты на руке проигравшего, «могнул», шулер) копятся за матч мелким счётом, идут в щелбаны и статистику, но исход решают победы.

**Босс недели.** Каждый понедельник — новый босс со своим правилом (8 по кругу): козырь каждый ход, без одиночек, 4 джокера, подкидывание одиночками, заряд за каждую защиту, рука 10 карт, перекрытие без лимита, без козырей. Одна попытка в день, победа — рубашка недели. **Сезон** — месяц: свои очки и таблица, лучший получает титул «Чемпион месяца».

**Блиц.** Шахматные часы: у каждого 2,5 минуты на всю партию, тикают только в свой ход. Время кончилось — партия проиграна, штраф по картам на руке, но не меньше 3.

**Обучение.** Три урока за 2 минуты против Учителя: покрой пару, перекрой стритом, подкинь. Предлагается при первом запуске, всегда есть в меню.

## Наборы правил

- **Классика** — комбинации, подкидывание (по номиналу и по типу) и перевод.
- **Полные** — плюс «могнул», заряд и карты-действия, перекрытие и апгрейд.

В своей игре и онлайне набор выбирается в «Своей игре», настройках или лобби (онлайн — у хозяина стола), по умолчанию «Полные». Ежедневная раздача — «Полные». В карьере правила открываются по районам: Подъезд — классика без перевода, Двор — перевод, Рынок — «могнул» и заряд, Вокзал — перекрытие и апгрейд, Казино — всё. Перед первой партией в районе — карточка «Новое правило» с примером.

## Режимы

- **Карьера «С подъезда в казино»** — 5 районов, по двое соседей и босс: Бабка у подъезда, Вахтёр, Таксист, Мажор, Шулер. За районы и достижения открываются рубашки, столы и музыка.
- **Своя игра** — Студент, Дядя Валера или Шулер.
- **Ежедневная раздача** — одна колода для всех в этот день, результат копируется как карточка для чата.
- **Онлайн** — с другом по коду стола, с реакциями и реваншем.

Подсказки уходят с опытом: новичок видит всё, игрок — только подсветку, профи — только название комбинации. В онлайне подсказки выключены у обоих.

## Компания 3–4

Дурак на троих или четверых — с ботами или онлайн с друзьями (пустые места занимают боты). Правила «Классики»: атакуют по часовой, подкидывают все, кроме защитника, перевод — следующему. Приглашение — ссылка `?mt=код` или кнопка в лобби, в Telegram — `startapp=m_код`.

## Онлайн

Ходы передаются через публичный MQTT-брокер по защищённому WebSocket (broker.emqx.io, запасные — HiveMQ и test.mosquitto.org). Свой сервер не нужен, и это работает через мобильный интернет, где прямое соединение между телефонами обычно не проходит. Брокер можно задать вручную: `?broker=wss://адрес`.

1. Нажми «Онлайн» → «Создать стол» → «Позвать друга ссылкой». В Telegram откроется выбор чата, в браузере — «Поделиться».
2. Друг жмёт на ссылку и сразу садится за стол. Можно и по старинке: открыть сайт, «Онлайн», ввести код.
3. Обновил страницу посреди партии — вернёшься за тот же стол (и хозяин, и гость). Если у вас разные версии игры, оба увидят «обнови страницу».
4. Партию ведёт хозяин стола. Гость получает только свою руку и число карт соперника, чужие карты к нему не уходят.
5. На ход 30 секунд. Матч в онлайне — формат выбирает хозяин (одна партия, до 2 или до 3 побед). Время вышло — игра сама говорит «Беру», «Бито» или «Хватит», а в атаке ходит младшей картой.

## Запуск

Сборка не нужна, это статический сайт.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

Settings → Pages → Source: «Deploy from a branch» → ветка `main`, папка `/ (root)`. Через минуту сайт будет на `https://<логин>.github.io/<репозиторий>/`. Эту ссылку и кидаешь другу.

## Устройство

| Файл | Что внутри |
|---|---|
| `index.html` | разметка стола, лобби и правил |
| `css/style.css` | стиль, вёрстка для телефона и для ПК (от 900 px) |
| `js/rules.js` | колода, джокеры, оценка комбинаций, кто кого бьёт, перевод, подсказки |
| `js/engine.js` | ход партии, матч до N побед, правила босса недели, таймер онлайн |
| `js/weekly.js` | босс недели и сезоны |
| `js/bot.js` | соперники и боссы карьеры |
| `js/meta.js` | хайп-фразы, прогресс, карьера, ежедневная раздача, достижения, награды |
| `js/audio.js` | музыка и звуки (Web Audio, без файлов) |
| `js/vfx.js` | искры, конфетти, вылет карт-действий, скины стола |
| `js/net.js` | онлайн-стол: что видит гость, как ходы доходят до хозяина |
| `js/transport-mqtt.js` | канал связи для сайта (MQTT по WebSocket) |
| `js/transport-room.js` | канал связи для страницы внутри Claude |
| `js/tg.js` | запуск внутри Telegram, ссылка-приглашение, вибрация |
| `sw.js`, `manifest.webmanifest` | установка на экран и офлайн |
| `js/ui.js` | отрисовка, анимации, подсказки, лобби, клавиатура |
| `tools/build-artifact.py` | собирает всё в одну страницу для Claude |

На ПК работает клавиатура: `Enter` — главная кнопка, `B` — правая кнопка («Беру», «Бито», «Хватит»), `H` — подсказка, `M` — меню, `Esc` — снять выбор.
