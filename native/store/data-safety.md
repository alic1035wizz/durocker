# Раздел «Безопасность данных» (Data safety) — шпаргалка

Заполняется в Play Console → Политика и программы → Безопасность данных. Ниже ответы для текущей версии. Если подключите облако Google Apps Script, ответы остаются теми же. **Отвечайте честно: если в игре что-то поменяется (реклама, аналитика, пуши), обновите форму.**

## Общее
| Вопрос | Ответ |
|---|---|
| Собирает ли приложение пользовательские данные? | **Да** (ник и игровая статистика при онлайн-режимах) |
| Шифруются ли данные при передаче? | **Да** (HTTPS / WSS) |
| Можно ли запросить удаление данных? | **Да** — письмом на alic1035wizz@gmail.com (адрес в политике) |
| Ссылка на политику конфиденциальности | `https://alic1035wizz.github.io/durocker/privacy.html` |
| Реклама / покупки | **Нет** |

## Типы данных
Отмечайте только перечисленное, всё остальное — «Нет».

| Категория → тип | Собирается | Передаётся третьим | Обязательно или по желанию | Зачем |
|---|---|---|---|---|
| Личная информация → **Имя** (это ник, придуманный игроком) | Да | Да — виден другим игрокам за столом и в таблице лидеров | **Необязательно** (только в онлайн-режимах) | Функции приложения |
| Личная информация → **Идентификаторы пользователя** (случайный id игрока) | Да | Нет (виден только сервису рейтинга и участникам стола) | Необязательно | Функции приложения, предотвращение мошенничества |
| Действия в приложении → **Взаимодействие с приложением** (результаты партий, рейтинг, очки) | Да | Да — рейтинг виден другим | Необязательно | Функции приложения |

Что отметить «Нет» (приложение этого НЕ собирает): местоположение, имя/почта/адрес/телефон, финансовая информация, здоровье, сообщения, фото и видео, аудио, файлы, календарь, контакты, история поиска/просмотров, данные об устройстве и сбоях, идентификатор рекламы.

> Про «передаётся третьим»: данные уходят на публичный MQTT-брокер и в Google Таблицу проекта (это сервис-провайдеры), а ник и рейтинг видны другим игрокам. Если не уверены — безопаснее ответить «передаётся» для ника и рейтинга, как в таблице.

## Практики безопасности
- Данные шифруются при передаче: **Да**.
- Можно запросить удаление: **Да**.
- «Соответствует политике для семей»: **Нет** (приложение не для детей до 13).
