# Анкета возрастного рейтинга (IARC) и целевая аудитория

Play Console → Политика и программы → Контент приложения → Оценка контента. Категория: **Игра**. Отвечайте честно: неточные ответы могут привести к блокировке. Ниже — как я бы ответил.

| Вопрос | Ответ | Пояснение |
|---|---|---|
| Насилие | Нет | Карточная игра, мультяшные портреты |
| Кровь, жестокость | Нет | |
| Сексуальный контент, нагота | Нет | |
| Ненормативная лексика / грубый юмор | **Да, лёгкая** | В репликах есть мат под звёздочками («грубые» варианты); при желании отключается в настройках |
| Запрещённые вещества (наркотики, алкоголь, табак) | Нет | У персонажа Михалыча папироса на портрете — можно отметить «упоминание табака» как мягкий вариант |
| **Азартные игры** | **«Имитация азартных игр»: Да** | Казино-тематика, ставки и удвоение **внутриигровыми фишками**, сундуки. Настоящих денег нет, фишки нельзя купить и вывести. Это «simulated gambling» — честнее ответить «да», рейтинг может быть повыше (ориентир: PEGI 12 / ESRB Teen / USK 12) |
| Реальные деньги, покупки в приложении | Нет | |
| Взаимодействие пользователей | **Да (ограниченное)** | Онлайн-партии, ники, готовые реакции; свободного чата нет |
| Делится местоположением | Нет | |
| Цифровые покупки | Нет | |

## Целевая аудитория (Target audience)
- Выберите **16–17 и 18+** (или 13–15, 16–17, 18+). **Не выбирайте группы до 13 лет**, иначе придётся соблюдать правила Play для семей и детей (запрет на ряд SDK и функций).
- «Привлекает ли приложение детей?» — **Нет**.

## Другое
- Приложение не относится к «новостным» и «COVID-19».
- Реклама: **нет**. Это значит, объявление «Содержит рекламу» не ставится.
- Конфиденциальность: ссылка на `privacy.html` (см. data-safety.md).
- Доступ к приложению: **весь функционал открыт без входа** (аккаунт не нужен).
